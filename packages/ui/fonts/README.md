# Schriften (lokal mitgeliefert, TD-04)

Variable Schriften (Achse `wght`, Zeichensatz latin inkl. Umlaute und ß) aus den Fontsource-Paketen
`@fontsource-variable/figtree` und `@fontsource-variable/bricolage-grotesque` 5.3.0, Lizenz **SIL Open Font License 1.1**
(`OFL-*.txt`). Eingebunden per `next/font/local` in `src/app/layout.tsx` und `apps/backup/src/app/layout.tsx` – der Build
lädt nichts mehr aus dem Netz (Docker-Build, Offline-Bundle, ISO).
